## review-animations verdict (issue #282, home list)

| Before | After | Why |
| --- | --- | --- |
| `.wgi-line-row { transition: background-color 240ms cubic-bezier(0.19,1,0.22,1) }` carried both the hover tint and the settle wash on one property | `.wgi-list-row > td { transition: background-color var(--motion-micro-duration) var(--motion-exit), box-shadow 240ms cubic-bezier(0.19,1,0.22,1) }`; the wash is an inset shadow (`[data-settled] > td { box-shadow: inset 0 0 0 100vmax var(--color-mint-2); transition: none }`) | Hover and open tints are micro states seen hundreds of times a day, so they take the 150ms registry beat; the settle wash keeps its 240ms exhale (carried over unchanged from 4e889fb) on a second property so the two never share a duration. Table rows cannot round or reliably paint, so the paint lives on the cells. |
| `.appt-line-trigger` (whole-row block) `transition: background-color var(--motion-micro-duration) var(--motion-exit)` | `.appt-line-trigger` (chevron button) `transition: background-color …, color …` both on `--motion-micro-duration` / `--motion-exit` | The trigger is now the chevron at the row's end; ink only, micro beat, named properties. |
| no rail | `.wgi-list-thumb { transition: background-color var(--motion-micro-duration) var(--motion-exit) }`; hover ink under `@media (hover: hover) and (pointer: fine)` with `cursor: grab`; `[data-held]` wins with `cursor: grabbing` | Only ink animates on the thumb. Its transform and height never transition (Base UI moves it with inline transforms), so the thumb never lags the pointer; held state paints on the pointerdown frame. |
| `.appt-line-trigger:hover` row hover ungated | `@media (hover: hover) { .wgi-list-row:hover > td … }` | Touch devices never see a stuck hover tint. |
| `.appt-line [data-col="avatar"]` rules | removed | The avatar column is not in the approved frame; no motion attached. |
| `.wgi-popover`, `.wgi-sheet` enter/exit rules, `[data-instant]`, reduced-motion `transform: none` overrides | unchanged | The record-card popover, the full-record sheet and their reduced-motion temperament are inherited from 4e889fb as they were; the popover only gained a row `anchor`. |

Reduced motion: every new rule is a `transition` on ink (background-color, color, box-shadow), so the blanket reset in `globals.css` `@layer base` collapses them to 0.001ms; the settle wash becomes an instant tint that clears with the 200ms timer, the thumb and chevron change ink instantly. Scroll position never animates in any mode (`scroll-behavior: auto` on the viewport). No `@starting-style`, no keyframes and no `motion/react` calls were added; the skeleton sweep (`wgi-skeleton`) is unchanged.

Verdict: **Approve.** Nothing enters from `scale(0)`, no `ease-in`, no `transition: all`, no layout property animates, no keyboard-initiated motion (Escape and keyboard scrolls are instant), hover is gated behind hover/pointer media, and the thumb is deliberately not eased.
